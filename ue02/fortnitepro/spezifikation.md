# Terminplaner

## 1. Worum geht es?

Mit dem Terminplaner können Leute einen Termin planen und andere dazu einladen.

Zum Beispiel jemand möchte Termine planen dann brauch er das.

## 2. Wer benutzt das?

Es gibt zwei Arten von Benutzern:

- Organisator
- Teilnehmer 

Zum Beispoel: es gibt einen Organisator oder viele Teilnehmner

## 3. Was soll die Software können?


1. Man kann sich anmelden.
2. Man kann einen Termin anlegen (Titel, Datum, Uhrzeit, Ort).
3. Man kann andere Personen einladen.
4. Teilnehmer können zusagen oder absagen.
5. Man sieht alle seine Termine in einer Liste.

## 4. Welche Daten gibt es?
 
 
| Info | Daten |
|---|---|
| Benutzer | Name, E-Mail, Passwort |
| Termin | Titel, Datum, Uhrzeit, Ort |
| Einladung | Termin, Benutzer, Zusage/Absage |
