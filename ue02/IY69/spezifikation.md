## 1. Zielbestimmung und Zielgruppen 
Das System dient Lehrenden zur Bereitstellung und Studierenden zur Buchung von Sprechstunden.

## 2. Funktionale Anforderungen 
Das System muss nach einer erfolgreichen Buchung eine iCal-Datei zum Download generieren. 

## 3. Nicht-funktionale Anforderungen 
Das System muss über die bestehenden Hochschulkonten abgesichert sein und stabil laufen.

## 4. Datenmodell und Schnittstellen 
Ein Termin besteht aus einer ID, dem Namen der Lehrkraft, dem Raum sowie Start- und Endzeit.
