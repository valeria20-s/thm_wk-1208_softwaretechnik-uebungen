## Ziel

Der Thm einen Terminplaner entwickeln

## Schritt für Schritt beschreiben, wie ein Termin gebucht wird

1. Kunde trägt Wunschtermin in eine Eingabefeld ein
2. System sendet die Nachricht an die Fachkraft der Thm
3. Termin wird von der fachkraft bestätigt oder es wird eine Ablehnung dieses Termins mit drei möglichen Ausweichterminen angegeben
4. System sendet die Antwort an den Kunden zurück
5. Kunde kann sich einen neuen Termin aussuchen oder ablehnen und stattdessen Telefonisch einen Termin vereinbaren
