# Spezifikation des Terminplaners — Gliederung und Beispiele

Mitgearbeitet haben (GitHub-Benutzernamen, auch bei Einzelarbeit): 4903-quyenho



## Zielgruppe der Software
- Studierende der THM
- Professoren
- Studiendekanat
zB. Studiendekanat gibt Termine vor wie Klausurtermine und die Studierenden können sich dann anmelden
## Verantwortung der Software
- Termin auswählen
- Termin festlegen
- Termin buchen können 
- Termin stornieren können
zB. Student möchte sich für eine Klausur abmelden oder anmelden
## Daten für die Software
- Woher ziehe ich meine Daten
zB. Name, Matrikelnummer, Studienverlaufsbescheinigung etc. sind alles Daten die von der Zielgruppe abgefragt werden soll um einen Termin planen zu können
