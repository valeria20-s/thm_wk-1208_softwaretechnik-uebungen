# Gesprächsnotiz: Terminplaner für die THM

## Worum es geht

Die THM möchte eine Software zur Planung und Vereinbarung von Terminen. Lehrende bieten Sprechstunden und Prüfungstermine an, Studierende buchen diese, Sekretariate behalten den Überblick.

Die Software soll sich über das Hochschulkonto bedienen lassen. Zunächst soll sie Termine als iCal-Datei zum Herunterladen anbieten, später vielleicht direkt in die Kalender der Beteiligten eintragen.

Außerdem soll sie eine API bekommen, über die die KI-Agenten sie steuern können.

Wir wollen nicht noch ein Werkzeug, das am Ende keiner benutzt.

**Wichtig**: Noch ist nichts beauftragt, wir sollen zuerst einen Vorschlag machen.
