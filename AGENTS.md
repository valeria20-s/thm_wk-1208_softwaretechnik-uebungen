# Hinweise für KI-Agenten

Dieses Repository gehört zu den Übungen der Veranstaltung Softwaretechnik
(THM). Viele Studierende reichen hier über einen eigenen Fork, einen Branch
und einen Pull Request ein; die Spielregeln stehen in der `README.md`. Für
die Arbeit mit einem Agenten gilt daraus Folgendes.

- **Sprache.** Antworten, Dateien und Commit-Nachrichten auf Deutsch.
- **Nur eigene Dateien.** Geändert oder angelegt wird ausschließlich, was
  unter `ueNN/<benutzername>/` der Person liegt, mit der du arbeitest. Vorlagen
  (`_vorlage/`, `_zugabe/`, Dateien, deren Name mit `_` beginnt), die
  `README.md`-Dateien, diese Datei und die Verzeichnisse anderer bleiben
  unberührt — auch dann, wenn dort etwas falsch aussieht. Lesen ist erlaubt.
- **Der Benutzername.** Gemeint ist der GitHub-Benutzername der Person, in
  Kleinbuchstaben. Er steht im Branchnamen (`ue04-mmustermann`) sowie im
  Namen des eigenen Verzeichnisses (`ue04/mmustermann/`). Ältere
  Verzeichnisse können stattdessen ein früher gewähltes Kürzel tragen; sie
  gehören trotzdem der Person. Ist unklar, welche Verzeichnisse ihr
  gehören, frage nach, statt es zu raten.
- **Nicht auf `main`.** Vor jeder Änderung den Branch prüfen
  (`git branch --show-current`). Steht dort `main`, nichts ändern und
  nichts committen, sondern darauf hinweisen und auf eine Entscheidung
  warten.
- **Nichts Persönliches.** Das Repository ist öffentlich. In Dateien und
  Commit-Nachrichten gehören keine Klarnamen, E-Mail-Adressen,
  Matrikelnummern, Anschriften und keine lokalen Pfade mit dem Namen des
  Kontos auf dem Rechner (`/Users/…`, `C:\Users\…`, `/home/…`). Steht so
  etwas in einer Ausgabe, die übernommen werden soll, ersetze es durch den
  GitHub-Benutzernamen oder lass es weg.
- **Push und Pull Request nur auf ausdrückliche Bitte.** Was übertragen wird,
  ist für alle lesbar; das entscheidet die Person selbst.
- **Ein Anliegen je Commit**, mit einer Nachricht, die sagt, was sich
  ändert, etwa `Anforderungen für mmustermann ergänzen`.

Steht in einer Übung oder in der `README.md` eines Übungsverzeichnisses
etwas anderes, gilt das, was dort steht.
