## Das erwarte ich von der Veranstaltung

Ich möchte in dieser Veranstaltung vor allem lernen, wie man größere Softwareprojekte richtig plant und strukturiert. Bisher habe ich bei meinen eigenen Projekten vieles einfach ausprobiert und dabei gelernt. Jetzt würde ich gerne verstehen, wie man von Anfang an besser vorgeht und sauberen, übersichtlichen Code schreibt.

Besonders interessiert mich die Softwarearchitektur. Ich möchte verstehen, wie man eine Anwendung so aufbaut, dass sie auch bei neuen Funktionen übersichtlich und leicht erweiterbar bleibt. Außerdem würde ich gerne lernen, wie ein Softwareprojekt von der ersten Idee über die Planung bis zur fertigen Anwendung entsteht.

Spannend finde ich auch, wie Entwickler in Unternehmen zusammenarbeiten, zum Beispiel mit Git, GitHub und Code Reviews. Ich möchte lernen, mich besser in fremden Code einzuarbeiten, Software richtig zu testen und Fehler systematisch zu finden.

Wichtig ist mir außerdem, dass der Code langfristig verständlich und wartbar bleibt. Besonders freue ich mich auf praktische Übungen und echte Projekte, bei denen man das Gelernte direkt anwenden kann.

Mein Ziel ist es, die neuen Kenntnisse auch für meine eigene Web-App mit Java und Spring Boot zu nutzen.
